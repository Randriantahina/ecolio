# memory/ · project memory

Read order at every session start: `status.md` → `roadmap.md` → active file in `phases/` → latest `changelog/` month. `architecture.md` and `decisions/` on demand. Rules: `.claude/rules/process/00-session-protocol.md` and `02-memory-journal.md`.

| Path | Role |
|------|------|
| `status.md` | now: in progress, last done, next action, blockers |
| `roadmap.md` | phases with checkboxes and definition of done |
| `phases/` | task checklist per phase |
| `changelog/` | one line per change, per month |
| `decisions/` | why a choice was made |
| `architecture.md` | what really exists |
| `project-brief.md` | what the product is |
